# Ejemplos de casos resueltos

Un archivo por caso auditado (p. ej. `examples/<proyecto>_<descriptor>.md`), resumiendo:
clasificación del arquetipo, resultado general, excepciones aplicadas y por qué, y — si el caso
expuso un hueco en `standards.md` — qué cambió y por qué.

**Nunca** se copia aquí un valor real de secreto, contraseña, clave ni dato personal. Se describe
el hallazgo en términos generales ("se encontró una clave de API en texto plano en una celda de
hoja de cálculo"), nunca el valor.

Sirve para que una auditoría futura no re-derive desde cero un caso de forma parecida.
