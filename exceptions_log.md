# Registro de excepciones

Registro **factual**: se añade una fila cada vez que ocurre una decisión de excepción real
(auto-detectada o declarada por el usuario). No requiere ceremonia de changelog para la fila en
sí. Nunca se copia aquí un valor real de secreto ni un dato personal — se describe el hallazgo.

| Fecha | Proyecto | Ítem / hallazgo | Tipo (desajuste de alcance / renuncia a control / riesgo aceptado) | Autoridad (nombre, rol) | Motivo |
|---|---|---|---|---|---|
| _(vacío en v0.0)_ | | | | | |
